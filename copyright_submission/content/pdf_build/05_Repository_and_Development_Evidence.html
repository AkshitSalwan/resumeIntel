Implementation boundary and limitations

  • The primary application performs deterministic, taxonomy-alias-based matching and weighted evidence coverage; it is not an LLM-based evaluator.
  • Proficiency labels and confidence terms are heuristic evidence descriptions, not calibrated probabilities or verified ability.
  • Forecasting and QLoRA/future-skills code are separate experimental work. Forecasting is gated/unavailable in the UI; no trained adapter or validated forecast is represented as available.
  • The repository has no selected software license. Third-party dependencies, pretrained model terms, and data rights need separate review.
