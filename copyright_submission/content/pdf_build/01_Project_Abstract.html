ABSTRACT

ResumeIntel: An Explainable Resume Intelligence and Skill Gap Analysis Software System

Intended users. People reviewing a resume against a target job description, including resume owners and advisors. The repository does not establish an employer deployment.

1.1 Problem Background

Resume screening often reduces a resume and a job description to keyword overlap or an opaque score. That can hide whether a requirement has contextual work evidence, appears only in a skills list, is absent, or cannot be mapped reliably. Noisy extraction can further complicate review. Reviewers need traceable evidence and uncertainty when comparing stated experience with role requirements. ResumeIntel addresses this decision-support problem without claiming that textual matches establish competence, predict hiring, or reproduce an employer’s applicant tracking system.

1.2 Objective of the Project

The objective is to implement a secure, inspectable workflow that extracts resume text, identifies job requirements, links assessments to source evidence, and summarizes evidence coverage. Reproducible research tools also examine controlled text changes and compare results with a keyword baseline.

1.3 Proposed Solution / System Overview

ResumeIntel is a web application centered on a deterministic requirement-analysis engine. An authenticated user uploads a PDF or DOCX; file checks validate type, size, and signature. The user supplies a job description, normalized and parsed into recognized taxonomy and unresolved bullet requirements. Aliases locate resume evidence and section context. Each requirement receives a matched, partial, missing, or uncertain state, explanation, and weighted contribution. The application persists a structured report. A workspace runs baseline, counterfactual, and transformation experiments. Outputs describe evidence coverage; they do not establish candidate ability or employment outcomes.

1.4 Key Features or Functionality

The report links requirement states to resume excerpts and locations, distinguishes contextual support from skills-list mentions, and preserves unresolved requirements as uncertain. Required and preferred items receive different weights in a coverage score. Proficiency estimates cite supporting contexts and state uncertainty. A counterfactual score shows the arithmetic effect of changing one assessment state. Authenticated history and runs support repeatable review.

1.5 Technology / Method Used

The application uses Next.js, React, TypeScript, Supabase Auth, storage, and PostgreSQL with RLS. PDF.js and Mammoth extract PDF and DOCX text. An alias taxonomy, deterministic normalization, evidence rules, and weighted arithmetic implement analysis. Vitest and ESLint verify code.

1.6 Expected Outcome & Benefits

The outcome is a comparison that helps reviewers inspect requirements with support, where it occurs, and items remaining uncertain. Evidence excerpts and weights make the score auditable. Transformations support research into wording and formatting sensitivity. The tool cannot verify actual skill, infer protected characteristics, guarantee fairness, or replace judgment. Job-market modules remain experimental; no validated forecast or model is claimed.

1.7 Original Contribution Statement

ResumeIntel integrates requirement-level evidence, explicit uncertainty, transparent weighted coverage, and bounded counterfactual explanations in an authenticated workflow with traceable evidence.
