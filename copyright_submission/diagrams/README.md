# Source-derived diagrams

Each editable `.mmd` Mermaid source is paired with an SVG and PNG rendering generated from the same node/edge inventory. They describe inspected repository behavior, not a proposed architecture except where a figure explicitly labels an experimental/unavailable module.

1. `01_overall_architecture` — authenticated browser, API, deterministic analysis, private persistence, research, and the unavailable forecast module.
2. `02_resume_processing` — upload validation, PDF/DOCX extraction, text checks, and private persistence.
3. `03_requirement_matching` — job-description requirements, alias taxonomy, resume evidence, and four result states.
4. `04_score_and_explanation` — weighted evidence coverage and hypothetical one-requirement counterfactual.
5. `05_research_workspace` — baseline and implemented simple text transformations followed by persisted experiment results.
6. `06_future_skills_boundary` — separate experimental data pipeline. AI-assisted labels are excluded from initial training; the QLoRA gate is blocked; no trained adapter exists; forecasting UI is unavailable.
7. `07_database_security` — authenticated ownership, PostgreSQL row policy, private storage, and analysis results.

These diagrams are explanatory summaries. Code and feature-status references in `../verification/` are authoritative when interpreting details.
